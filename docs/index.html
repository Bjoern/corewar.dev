Debugger / Consoles



Native pMARS debugger help

The command line uses pMARS cdb, including expressions, command chains (~), loops, conditional commands, and macros. The original pmars.mac and mw.mac are preloaded. Enter help for native command help or macro to list macros.


step executes one instruction; native step 10 changes the current program counter to address 10 before executing. To execute ten instructions, use skip 9 or step~!10. Enter on an empty field recalls the last native command chain.


trace 100 and untrace 100 set and clear source-style breakpoints. edit, fill, and paged listings request their next input in the same field. Use the toolbar's Cancel button to interrupt a macro or prompt. Native reset cancels a command chain; the toolbar Reset (or reset battle) reloads the battle.


Files used by cdb live in this match's temporary browser filesystem. Shell commands are unavailable. Native text-panel macros share this browser output view. F5/F7/F8/F9 and navigation shortcuts invoke the real macros outside editable controls.
